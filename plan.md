# AstroJournal

## Description

As an Astronomy enthusiast, I love looking at the night sky. I observe different stars, constellations, and planets. But the problem is I often forget what I saw on what day or at what time. To record everything I observed, I need a journal-style tool. This is why I want to develop AstroJournal, which is an application-based journal to note down the things I’ve observed so far. I can easily search by date or time to see what I saw that night.
Not only I, but all other space enthusiasts like me can also use this application. It will build a habit to explore the vast space more.

## Features

1. Store date-wise observation data

2. Can delete any data at any time with selection

3. Can update previously stored data with selection

4. Filter data by observation type(different celestial object)

5. List all the previously stored data

6. Sort observation data by date

7. Can add picture of that celestial object

8. keeps track of regularity, which is called streaks in-app

9. It will have stats. The stats show the total number of times each celestial object was observed.
10. Text files as database.
